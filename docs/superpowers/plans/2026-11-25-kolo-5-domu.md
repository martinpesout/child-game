# Kolo 5 – Domů: implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hratelné poslední kolo (~3–4 min): zahrada se 3 obručemi → potůček (1 přechod) → plot s malým podzemním bludištěm → dvorek s kocourem „Na sochy“ → vlezení do domku a finále se všemi kamarády → závěrečná obrazovka hry.

**Architecture:** `Level5Home extends LevelBase` v jednom světě. Úseky jsou brány `'line'` (`GateTracker`) v pořadí; zahrada má vlastní 3 obruče (`GateTracker` obručí, úsek 1 = poslední obruč). Potůček je jeden rovný přechod (analytický pás vody, pád a návrat jako v kole 3). Plot přes celý svět, díra → `Underground` (malé bludiště) přes kolečkový přechod (stejné API `view3d`/`iris`/`exitIndicator` jako kolo 4). Kocour = čistá logika `CatWatch` + model `Cat`. Konec hry = nová obrazovka `'gameEnd'` ve `Flow`.

**Tech Stack:** Vite 6, TypeScript strict, three r170, Vitest + jsdom.

**Spec:** `docs/superpowers/specs/2026-11-25-kolo-5-domu-design.md`

## Global Constraints

- Kola 1–4 beze změny chování; všech 310 stávajících testů dál prochází.
- 5 úseků v pořadí (zahrada = 3. obruč, potůček, plot, dvorek, domek); lišta ikony `hoop`, `stone`, `paw`, `cat`, `house` + 3 bonusy (jahoda, mrkev, jablko).
- Potůček: 4 kameny + 1 leknín, mezery ≤ 1,0 m; pád jako v kole 3 (návrat na poslední pevné místo, nic se neztrácí).
- Bludiště ~10×5, řešitelné, kamínky, 1 vtipná velká věc (ne budík ani dinosaurus), 1 bonus.
- Kocour: spánek první cykly ~4–5 s, později ~2,5–3 s; varování ~1,5 s; dívá se ~2 s. Prohřešek = rychlost hamstera > 0,25 m/s během „dívá se“ mimo stinnou zónu úkrytu (kruh r 1,0 m, na straně odvrácené od kocoura). Prohřešek → „Mňau!“, křeček uteče k poslednímu úkrytu (nebo začátku dvorku). 2 prohřešky bez přečkaného pohledu mezi nimi → další spánek 2× delší, počítadlo se vynuluje.
- Při varování se zobrazí nápověda ✋; křeček se sám nezastaví.
- Finále ~5 s: ježek, veverka, žabka, krtek u domku mávají, hlášky postupně (ne přes sebe).
- Hlasy: `l5story`, `l5end` vypravěč; veverka/žabka/krtek/ježek stávající hlasy; kocour `ELEVENLABS_VOICE_CAT` → jinak vypravěč.
- Texty česky, krátké a veselé; komentáře v kódu anglicky.

## Review Focus

1. **Kocour se probudí, zatímco je křeček ve skoku nebo v pohybu po návratu** – po útěku k úkrytu má křeček chvilku klid (1 s bez vyhodnocení), aby ho kocour nechytil hned znovu. Test v Task 1.
2. **Dítě stojí za úkrytem a joystick drží** – ve stínu se smí hýbat; vyjít ze stínu během pohledu = prohřešek. Test v Task 1.
3. **Pauza / Znovu pod zemí nebo během finále** – po „Znovu“ čisté kolo na povrchu, bez podzemí a bez zbylých kamarádů ve scéně. Test v Task 5.
4. **Obruč vynechaná** – úsek zahrada se nesplní, další úseky se nepočítají, ukazuje šipka; po dohnání obruče vše pokračuje. Test v Task 5.
5. **Vlezení do domku před dokončením úseků** – domek se otevře (tlačítko „zalézt“) jen po úseku kocour; jinak dveře zavřené. Test v Task 5.

### Task 1: Logika kocoura `CatWatch`

**Files:** Create `src/levels/catWatch.ts`; Test `tests/levels/catWatch.test.ts`

**Interfaces – Produces:**
- `type CatState = 'sleep' | 'warn' | 'look'`
- `class CatWatch { constructor(opts?: { firstSleep?: number /*4.5*/; laterSleep?: number /*2.8*/; warn?: number /*1.5*/; look?: number /*2*/; easyAfter?: number /*2 cycles*/ }); state: CatState; readonly t: number; update(dt: number, hamster: { speed: number; hidden: boolean }): 'caught' | null; readonly cycles: number; readonly sleepLeft: number }`
- Pravidla: `sleep` → `warn` → `look` → `sleep`; první `easyAfter` spánky `firstSleep`, pak `laterSleep`. V `look`: `speed > 0.25 && !hidden` → `'caught'` (jen jednou za pohled), stav pokračuje. Po `caught` grace 1 s bez vyhodnocení. Přečkaný pohled (bez caught) vynuluje počítadlo prohřešků. 2 prohřešky bez přečkaného pohledu → příští spánek 2× delší, počítadlo 0.
- [ ] **Step 1: Failing tests** – `cyklus spí → varuje → dívá se → spí s danými časy`; `první dva spánky delší, pak kratší`; `pohyb při pohledu = caught (jednou za pohled)`; `stání nebo stín = v pořádku`; `pohyb při spánku/varování nevadí`; `po caught 1 s klid`; `2 prohřešky za sebou → další spánek 2× delší, pak normální`; `přečkaný pohled vynuluje počítadlo`.
- [ ] **Step 2–4:** fail → implement → pass (`npx vitest run tests/levels/catWatch.test.ts`).
- [ ] **Step 5: Commit** – `feat: logika kocoura na sochy`
