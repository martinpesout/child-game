# Hudba na pozadí

Uložte sem skladbu jako `theme.mp3` (nebo `theme.m4a`). Hra ji pak přehrává dokola místo generované melodie;
vypíná se stejným tlačítkem zvuku. Když tu soubor není, hraje generovaná melodie.

Tip: ať konec skladby plynule navazuje na začátek (smyčka). Hlasitost upravíte v `src/audio/sfx.ts` (`TRACK_VOL`).
